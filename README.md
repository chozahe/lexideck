# Lexideck

Локальное расширение Chrome и Brave для перевода выделенного текста и текста из выбранной области комикса.

## Установка для разработки

1. Выполните `npm install` и `npm run build`.
2. Откройте `chrome://extensions` (в Brave — `brave://extensions`), включите режим разработчика и нажмите «Загрузить распакованное расширение».
3. Выберите папку `dist`.
4. Откройте настройки API в боковой панели и задайте URL OpenAI-compatible API, идентификатор модели с поддержкой изображений и ключ.

URL можно указать как адрес API, например `https://api.example.com/v1`, или как полный адрес `/chat/completions`. Расширение хранит настройки локально в профиле браузера.

## Перевод текста

Если горячая клавиша нажата без выделенного текста, она включает выбор прямоугольной области комикса. Обведите реплики мышью. Распознанный текст откроется в боковой панели — проверьте и при необходимости исправьте его, затем нажмите кнопку подтверждения и перевода.

В запрос vision-модели включается только обрезанная выбранная область. Изображение не записывается в постоянное локальное хранилище; временная копия удаляется после передачи в панель.

Выделите текст на странице и выберите «Перевести выделенный текст в Lexideck» в контекстном меню либо нажмите `Ctrl+Shift+Y` (`⌘+Shift+Y` на macOS). Перевод и значения слов появятся в боковой панели. Языки по умолчанию — английский → русский; их можно изменить в настройках API.

Если сочетание клавиш занято, его можно изменить на `chrome://extensions/shortcuts` или `brave://extensions/shortcuts`. Текст можно также ввести или исправить непосредственно в панели.

## Повторение карточек

Сохраните слова или устойчивые выражения в словарь, затем нажмите «Перейти к повторению»
в боковой панели. Расширение откроет занятие в отдельной вкладке. Сначала предлагаются карточки, срок повторения которых
уже наступил, затем новые карточки. На лицевой стороне показана основная форма;
кнопка «Показать ответ» открывает одно значение, его контексты и примеры модели.
Оцените ответ: «Не вспомнил», «Трудно», «Хорошо» или «Легко».

Расписание рассчитывает [ts-fsrs](https://github.com/open-spaced-repetition/ts-fsrs)
с параметрами по умолчанию. У значений карточки общее расписание: они чередуются
после каждой оценки. Следующий срок виден в словаре. Состояние FSRS, история
оценок и очередность значений сохраняются локально; API для занятия не нужен.
Карточки и расписание общие для панели и вкладки. Если срок наступил во время занятия,
нажмите «Начать занятие» снова.

По умолчанию можно начать изучение 10 новых карточек за день. Лимит меняется
на странице повторения; значение 0 оставляет только повторения. Новая карточка
учитывается после первой оценки, а повторные оценки не расходуют лимит.
День определяется по местному времени браузера; перезапуск вкладки счётчик
не сбрасывает.

После оценки карточки засчитывается день занятия. Страница повторения показывает серию
последовательных дней и достижения за первую оценку, десять оценок и серию
из трёх дней. Пропуск дня сбрасывает текущую серию, сохраняя словарь и историю.

Сборка включает локальную копию библиотеки FSRS и её лицензию, без загрузки
кода с CDN. `src/vendor/` создаётся автоматически при сборке и запуске тестов.

## Проверки

```sh
npx playwright install chromium
npm run typecheck
npm test
npm run build
```

Сквозные проверки запускают Chromium и контролируемый OpenAI-compatible API на локальном сервере.
