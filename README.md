# Lexideck

Локальное расширение Chrome и Brave для перевода выделенного текста и разбора значений слов в контексте.

## Установка для разработки

1. Выполните `npm install` и `npm run build`.
2. Откройте `chrome://extensions` (в Brave — `brave://extensions`), включите режим разработчика и нажмите «Загрузить распакованное расширение».
3. Выберите папку `dist`.
4. Откройте настройки API в боковой панели и задайте URL OpenAI-compatible API, идентификатор модели и ключ.

URL можно указать как адрес API, например `https://api.example.com/v1`, или как полный адрес `/chat/completions`. Расширение хранит настройки локально в профиле браузера.

## Перевод текста

Выделите текст на странице и выберите «Перевести выделенный текст в Lexideck» в контекстном меню либо нажмите `Ctrl+Shift+Y` (`⌘+Shift+Y` на macOS). Перевод и значения слов появятся в боковой панели. Языки по умолчанию — английский → русский; их можно изменить в настройках API.

Если сочетание клавиш занято, его можно изменить на `chrome://extensions/shortcuts` или `brave://extensions/shortcuts`. Текст можно также ввести или исправить непосредственно в панели.

## Проверки

```sh
npx playwright install chromium
npm run typecheck
npm test
npm run build
```

Сквозные проверки запускают Chromium и контролируемый OpenAI-compatible API на локальном сервере.
