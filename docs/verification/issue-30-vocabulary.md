# Проверка словаря для #30

## Метод

Playwright создал 1000 локальных карточек с уникальными id и значениями, дождался отображения первой порции, нашёл значение `needle at the end` у карточки `card-997`, быстро заменил запрос, прошёл все 20 страниц по 50 записей и раскрыл карточку на последней странице. Проверка не опирается на общее число DOM-узлов. Сценарий также проверяет ленивое создание подробностей. Отдельный сценарий изменяет карточку из второй вкладки и проверяет, что раскрытие и фокус по id остаются на прежней карточке.

Время записано Playwright-тестом через `Date.now()` вокруг взаимодействий и ожиданий результата. Это время сценария в браузерном harness, а не чистая длительность функции поиска: оно включает ожидания Playwright и обработку событий.

## Результат

- Среда: Linux x86_64, Node.js 26.8.1, Playwright 1.63.0, headless Chromium `153.0.8010.12`.
- Последний полный прогон: поиск — **74 мс**; 19 переходов страниц и раскрытие подробностей — **1043 мс**.
- Найдено значение у 998-й карточки; отображены все 20 страниц; на каждой странице не более 50 карточек.
- При изменении другой записи во второй вкладке проверка сохранила фокус на `stable-b` и его раскрытое состояние.
- Проверка ограничена тестовым Chromium и локальным хранилищем Playwright; производительность реального профиля Chrome/Brave и экранное положение при прокрутке вручную не измерялись.
