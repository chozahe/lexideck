# Проверка перевода области комикса в Brave — #10

Проверено в Brave Browser 154.1.96.61 на Linux/Wayland, в отдельном чистом
профиле. Настоящее расширение Manifest V3; `sidePanel.open()` и захват экрана
не подменяются. Ответы API управляемые через `tests/server.js`.

## Обнаруженные причины

Исходный путь ожидал обрезания изображения и записи в хранилище перед
`sidePanel.open()`. В настоящем Brave панель после завершения области
не открывалась.

При переносе открытия раньше возникла ещё одна воспроизводимая гонка:
сразу после удаления DOM-слоя выделения композитор иногда сохранял его
на снимке. Вместо синего пикселя API получал `[26,46,208]`.

Исправленный путь использует callback сообщения content script, который
отвечает после двух кадров перерисовки. Затем callback `captureVisibleTab()`
сохраняет user gesture для открытия панели. Снимок уже зафиксирован до
изменения ширины страницы; асинхронное обрезание и запрос модели выполняются
после открытия. Изображение передаётся через `chrome.storage.session`,
потребляется панелью и не сохраняется в `chrome.storage.local`.

## Воспроизводимая проверка

```bash
node tests/server.js
node scripts/check-brave-region.js
```

Для отдельного порта: `PORT=4189 node tests/server.js`, затем
`BRAVE_TEST_ORIGIN=http://127.0.0.1:4189 node scripts/check-brave-region.js`.

Скрипт создаёт синий прямоугольник 80×70 CSS-пикселей у правого края красной
страницы, без выделенного текста, и отправляет настоящий `Ctrl+Shift+Y`
через `wtype`. Панель отсутствует среди DevTools targets до хоткея и во
время выделения. После движения мыши и отпускания кнопки возникает
настоящий target панели. Через DevTools читается видимый перевод:
`Она сняла пальто и надела пальто.`; поле ошибки пустое.

При выполненной проверке viewport оставался 1213 во время выделения и
уменьшился до 795 после открытия панели. Переданный API фрагмент был синим,
размером 121×106 физических пикселей при pixel ratio 1.5; учитывается
округление границ до целых пикселей. Это подтверждает, что панель не сместила
область до снимка, а слой выделения не попал в изображение.

Вывод скрипта:

```
PASS: закрытая панель → хоткей без текста → область → настоящая панель → распознавание и перевод; фрагмент 121×106 синий, viewport 1213→795.
```

## Остальные проверки и ограничения

Playwright: 12 пользовательских сценариев перевода и запуска расширения.
Проверены автоматическая цепочка, ход распознавания, ошибки, ручной повторный
перевод, сохранение слов и выражений, отсутствие изображения в постоянном
хранилище и запоздалые ответы при новом тексте или новой области.

Настоящий хоткей требует активного окна тестового Brave, графической сессии
Wayland и `wtype`. Скрипт ожидает фокус нового окна; смена активного окна
другой программой или пользователем может нарушить доставку хоткея.
Оценка качества внешней vision-модели не входит в эту проверку.
