# Трекер задач: GitHub

Задачи и спецификации хранятся в GitHub Issues.
Используй CLI `gh`; репозиторий определяется из git remote.

## Операции

- Создание: `gh issue create --title "..." --body-file <файл>`.
- Чтение с комментариями: `gh issue view <номер> --comments`.
- Список: `gh issue list --state open --json number,title,body,labels`.
  При необходимости используй фильтры `--label` и `--state`.
- Комментарий: `gh issue comment <номер> --body-file <файл>`.
- Добавление метки: `gh issue edit <номер> --add-label "<метка>"`.
- Удаление метки: `gh issue edit <номер> --remove-label "<метка>"`.
- Закрытие: `gh issue close <номер> --comment "..."`.

Многострочный текст передавай через файл, сохраняя переносы строк.

## Публикация и получение задач

«Опубликовать в трекере» означает создать GitHub Issue.
«Получить связанную задачу» означает прочитать её через
`gh issue view <номер> --comments`.

## Запросы через pull request

PRs as a request surface: no.

GitHub использует общую нумерацию задач и PR.
Для неоднозначной ссылки сначала проверь `gh pr view <номер>`,
затем `gh issue view <номер>`.

## Навигация wayfinder

- Карта работы — задача с меткой `wayfinder:map`,
  содержащая заметки, принятые решения и открытые вопросы.
- Дочерние задачи связывай с картой через GitHub sub-issues.
  Если они недоступны, используй список задач в карте и
  строку `Part of #<номер>` в дочерней задаче.
- Для типов задач используй метки `wayfinder:research`,
  `wayfinder:prototype`, `wayfinder:grilling`, `wayfinder:task`.
- Блокировки записывай через встроенные зависимости GitHub.
  Для API используй числовой database id блокирующей задачи,
  а не её номер или node_id.
  Если зависимости недоступны, используй строку
  `Blocked by: #<номер>, #<номер>`.
- Следующая задача — первая в порядке карты открытая задача
  без исполнителя и открытых блокировок.
- При взятии задачи назначь себя:
  `gh issue edit <номер> --add-assignee @me`.
- После выполнения оставь результат в комментарии,
  закрой задачу и добавь вывод со ссылкой в решения карты.
