# Метки triage

| Роль навыка | Метка в трекере | Значение |
| --- | --- | --- |
| needs-triage | needs-triage | Требуется оценка сопровождающего |
| needs-info | needs-info | Ожидается дополнительная информация |
| ready-for-agent | ready-for-agent | Задача готова к автономной работе агента |
| ready-for-human | ready-for-human | Требуется реализация человеком |
| wontfix | wontfix | Задача не будет реализована |

Когда навык называет роль, используй соответствующую метку
из этой таблицы. Для изменения словаря редактируй второй столбец.
