# Локальное хранение с внешней языковой моделью

Словарь, расписание повторения, настройки и ключ API хранятся в профиле браузера пользователя; выделенные им текст или фрагмент изображения отправляются внешнему OpenAI-совместимому API для анализа, а исходное изображение не сохраняется. Этот вариант выбран ради простого старта без серверной части и синхронизации, сохраняя пользовательские данные на устройстве.
