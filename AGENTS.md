# Инструкции для агентов

## Язык

Общайся с пользователем на русском.
Пиши заголовки, описания задач и комментарии к ним на русском.
Документацию и пояснения к изменениям также пиши на русском.
Сохраняй исходное написание команд, путей, идентификаторов,
названий меток и технических терминов, требующих точного совпадения.

## Agent skills

### Трекер задач

Задачи и спецификации хранятся в GitHub Issues репозитория
chozahe/lexideck. Перед работой с задачами читай
`docs/agents/issue-tracker.md`.

### Метки triage

Используются пять стандартных меток. Перед сортировкой задач
читай `docs/agents/triage-labels.md`.

### Документация предметной области

Один контекст: `CONTEXT.md` в корне и решения в `docs/adr/`.
Перед изучением проекта читай `docs/agents/domain.md`.
