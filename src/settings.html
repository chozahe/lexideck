Перевод

Выберите язык исходного текста и язык, на который переводить.

Подключение API

Укажите базовый адрес, например https://api.example.com/v1, либо полный адрес, заканчивающийся на /chat/completions. Модель должна поддерживать OpenAI-compatible Chat Completions; для комиксов нужна поддержка изображений. Ключ хранится только в локальном хранилище этого профиля браузера и не входит в резервную копию. При переводе внешний сервис получает введённый текст, а при анализе комикса — только выбранную область изображения.

Допустим http:// или https://; можно указать базовый URL или полный endpoint. Укажите точный идентификатор модели из панели выбранного сервиса. Ключ передаётся выбранному API при запросе и хранится локально в этом профиле.

Чтобы начать перевод, заполните URL API, модель и ключ, затем проверьте подключение и сохраните настройки.

Повторение

Лимит новых карточек хранится локально. Значение 0 отключает новые карточки, но карточки, которым пора на повторение, останутся доступны.

Оформление

Тема сохраняется сразу после выбора, отдельно от кнопки сохранения настроек.
