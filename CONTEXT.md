# Помощник для изучения слов

Предметная область помощника, который переводит текст из комиксов, сохраняет слова и помогает их повторять.

## Чтение комиксов

**Область захвата**:
Выделенная пользователем часть изображения комикса, которую помощник анализирует.
_Избегать_: скриншот всей страницы, если речь только о выбранном фрагменте.

**Реплика**:
Текст, который модель извлекает из изображения; реплика может состоять из одного или нескольких предложений.
_Избегать_: OCR-результат.

**Контекст употребления**:
Фраза или предложение из комикса либо веб-страницы, в котором пользователь встретил слово.
_Избегать_: пример, если имеется в виду именно исходная фраза из комикса.

**Основная форма**:
Словарная форма слова, под которой сохраняются его изменённые формы.
_Избегать_: словоформа, если речь о форме, встретившейся в тексте.

**Устойчивое выражение**:
Сочетание из нескольких слов, которое изучается как единое целое и имеет отдельную карточку.
_Избегать_: набор отдельных слов, если перевод относится ко всему выражению.

**Пример модели**:
Дополнительное предложение с изучаемым словом, которое создала языковая модель.
_Избегать_: контекст употребления.

## Словарь и повторение

**Карточка слова**:
Словарная запись основной формы слова с одним или несколькими значениями, контекстами употребления и примерами модели; у всех значений слова общее расписание повторения.
_Избегать_: отдельная карточка на каждую встреченную фразу.

**Значение слова**:
Отдельный смысл слова, который определяется переводом и контекстом употребления.
_Избегать_: перевод без контекста, если слово многозначное.

**Интервальное повторение**:
Повторение карточек слова через интервалы, которые рассчитываются алгоритмом FSRS по ответам пользователя.
_Избегать_: фиксированный список слов без расписания.
